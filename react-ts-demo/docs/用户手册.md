# 青少年英语学习平台 用户手册

## 1. 简介

本项目是一个面向青少年的英语学习网页应用，集成了角色对话、词汇学习、听力训练、写作练习、口语练习、情绪记录等功能，并通过 AI 技术提供个性化学习体验。

**技术栈**：React 19 + TypeScript + Vite（前端）、Express 5 + Node.js（后端）、SQLite + Prisma（数据库）

---

## 2. 运行环境

### 前端

- 浏览器：Chrome 90+ / Firefox 88+ / Edge 90+（推荐 Chrome）
- 需支持 Web Audio API（用于听力/语音功能）

### 后端

- Node.js 18+
- SQLite（内置，无需单独安装）
- 网络：需能访问百度千帆 API、百度翻译 API

### 本地开发

需安装：

- Node.js 18+
- npm 9+

## 3. 安装与部署

### 3.1 拉取代码

```bash
git clone <仓库地址>
cd react-ts-demo
```

### 3.2 安装依赖

```bash
# 安装前端依赖
npm install

# 安装后端依赖
cd backend
npm install
cd ..
```

### 3.3 配置环境变量

在 `backend/` 目录下创建 `.env` 文件：

```env
DATABASE_URL="file:./prisma/dev.db"
QIANFAN_API_KEY=你的百度千帆API密钥
BAIDU_APPID=你的百度翻译AppID
BAIDU_SECRET_KEY=你的百度翻译密钥
NODE_ENV=development
```

### 3.4 初始化数据库

```bash
cd backend
npx prisma migrate dev
npx prisma db seed   # 导入预设角色和词库（如有）
cd ..
```

### 3.5 启动项目

```bash
# 终端1：启动后端（端口 3001）
cd backend
npm run server

# 终端2：启动前端（端口 5173）
cd ..
npm run dev
```

### 3.6 访问地址

- 前端页面：http://localhost:5173
- 后端 API：http://localhost:3001/api

> 前端通过 Vite 代理自动转发 `/api` 请求到后端，无需手动配置跨域。

## 4. 页面模块介绍

### 首页

应用主界面，展示角色列表和学习入口。包含导航栏、侧边栏、角色卡片区域。

### 导航栏

顶部导航，提供页面跳转、用户信息展示、退出登录入口。

### 主页侧边栏

展示多功能菜单：护眼功能、分享好友、设置、学习时长记录。

### 少儿页面侧边栏（ProfileSidebar）

展示当前用户的学习数据：累计学习时长、连续打卡天数、已掌握单词数、积分与勋章。

### 登录/注册弹窗

首次访问或未登录时弹出，支持账号注册、账号登录、游客模式三种方式。

### 角色选择界面（CharacterSelector）

展示所有可用角色（预设 + 自定义），点击角色进入对话。

### 聊天界面（ChatInterface）

与角色进行文字对话，支持 Live2D 动画角色展示、对话历史记录、角色记忆功能。

### 学习模式弹窗（LearningModeModal）

选择学习模式入口，包含英语学习、听力训练、写作练习等子模块。

### 词汇学习弹窗（VocabularyModal）

按单词本类型（初一、高一、四级、雅思等）学习单词，支持发音、释义查看、进度记录。

## 5. 功能操作说明

### 5.1 注册与登录

1. 打开首页，自动弹出登录弹窗
2. **注册**：填写用户名、密码、年龄，点击"注册"
   - 年龄分组：0-12岁（儿童）、13-17岁（青少年）、18岁+（成人），影响词库和内容推荐
3. **登录**：输入已注册的用户名和密码，点击"登录"
4. **游客模式**：点击"游客体验"，无需注册即可使用基础功能（数据不保存）

### 5.2 角色对话

1. 在首页选择一个角色（预设角色或自定义角色）
2. 进入聊天界面，在底部输入框输入消息，按回车或点击发送
3. AI 角色会根据其设定的性格和记忆进行回复
4. 对话历史自动保存，下次进入同一角色可继续上次对话

### 5.3 创建自定义角色

1. 在角色选择界面点击"创建角色"按钮
2. 填写角色名称、性格描述、背景故事等信息
3. 可上传角色头像
4. 点击"保存"，角色出现在角色列表中

### 5.4 单词学习

1. 点击导航栏或首页的"词汇学习"入口
2. 选择单词本类型（初一/高一/四六级/雅思/托福/少儿词库）
3. 逐词学习：查看单词、音标、释义、例句
4. 点击音频图标可收听单词发音
5. 标记"已掌握"或"待复习"，系统记录学习进度

### 5.5 复习单词

1. 进入"复习"模式，系统根据遗忘曲线推送待复习单词
2. 看到单词后先回忆释义，再翻转卡片查看答案
3. 选择"记住了"或"没记住"，系统调整下次复习时间

### 5.6 查看学习进度

1. 侧边栏实时显示：今日学习时长、连续打卡天数、累计掌握单词数
2. 点击"学习报告"查看周报/月报，包含学习趋势图表

### 5.7 听力训练

1. 进入学习模式弹窗，选择"听力训练"
2. 选择听力素材，点击播放
3. 完成听力题目，提交答案后查看解析

### 5.8 AI 语音对话

1. 在聊天界面点击麦克风图标，开始录音
2. 说完后松开，系统通过语音识别（ASR）将语音转为文字
3. 文字自动发送给角色，角色回复后可通过 TTS 朗读回复内容
4. 点击角色回复旁的音频图标收听语音回复

### 5.9 写作练习

1. 进入"写作练习"模块
2. 查看作文题目，在编辑框中输入作文
3. 提交后 AI 给出修改建议

## 6. 常见问题 FAQ

**Q：启动后端报错 `Cannot find module`？**
A：在 `backend/` 目录下执行 `npm install`，确保依赖已安装。

**Q：前端页面空白？**
A：检查前端是否正常启动（`npm run dev`），查看浏览器控制台报错信息。确认 Node.js 版本 ≥ 18。

**Q：API 请求失败（Network Error）？**
A：确认后端服务已启动（`npm run server`，端口 3001）。检查 `backend/.env` 文件是否存在且配置正确。

**Q：数据库连接失败？**
A：确认 `backend/.env` 中 `DATABASE_URL` 路径正确，并已执行 `npx prisma migrate dev` 初始化数据库。

**Q：语音/听力功能无声音？**
A：检查浏览器是否允许该网页使用麦克风和音频权限。确认 `QIANFAN_API_KEY` 配置正确。

**Q：翻译功能不可用？**
A：检查 `BAIDU_APPID` 和 `BAIDU_SECRET_KEY` 是否正确配置，确认百度翻译 API 账户有效。

**Q：游客模式数据丢失？**
A：游客模式数据仅保存在当前会话，刷新或关闭页面后清除。请注册账号以持久保存学习数据。
